# Anadolu'nun Büyülü Masalları | Sözlü Bellek Arşivi

Bu proje, Anadolu sözlü geleneğinden derlenen 8 masalın türlerine göre filtrelenebildiği, aranabildiği ve açılır pencere (`<dialog>`) üzerinden okunabildiği vize web projesidir.

## Tek Dosyadan Modüler Yapıya Geçiş
Önceki tek sayfalık yapı üç ayrı dosyaya bölünmüş ve harici dosya yollarıyla birbirine bağlanmıştır:
- `index.html`: Sayfa iskeleti, arama ve tür filtreleme alanı, masal okuma penceresi ve kaynakça bölümü (`style.css` ve `script.js` dosyalarına harici olarak bağlıdır).
- `style.css`: Renk değişkenleri, yazı tipi tanımları, grid yerleşimi, kart tasarımları ve duyarlı (`responsive`) stil kuralları.
- `script.js`: Masal verileri, Türkçe karakter uyumlu arama ve kategori filtreleme mantığı, modal açma/kapatma ve görsel yedekleme işlevleri.

## Dosya ve Klasör Yapısı
- `index.html`
- `style.css`
- `script.js`
- `images/` (Masal görselleri)
- `fonts/` (Varsa yerel yazı tipi dosyaları)
- `README.md`

## Kullanılan Teknolojiler
- HTML5
- CSS3
- JavaScript

## Çalıştırma
Proje dosyalarını indirip `index.html` dosyasını bir tarayıcıda veya yerel sunucuda açarak inceleyebilirsiniz.
